la chaîne de build, de test ou de développement ; aucune n'est une dépendance de production

| Chaîne                                                  | Niveau          | Décision                                                                                                                                                        |

Le poste de travail actuel expose le dépôt par un chemin UNC : les sous-processus `cmd.exe`
lancés par pnpm ignorent ce répertoire. Le lockfile a donc été régénéré depuis le chemin Linux
natif, mais ce sous-système utilise Node 18 alors que le projet exige Node 24. Avant fusion,
exécuter depuis un clone utilisant Node 24 :

```bash
pnpm install
pnpm audit --json
pnpm typecheck
pnpm lint
pnpm test
pnpm format:check
pnpm build
```

La CI doit être verte avant fusion. Toute nouvelle alerte doit être ajoutée à ce triage avec sa
décision explicite.
